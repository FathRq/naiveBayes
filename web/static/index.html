Dataset — ANTARA News

Dataset dikumpulkan sendiri dengan web scraping etis dari antaranews.com (scrapping_data.py), disimpan mentah ke HDFS, dibersihkan dengan Spark (33.776 baris bersih, 0 NULL), lalu dibuang 221 near-duplikat untuk skenario DEDUP.

Evaluasi Model — Eksperimen RAW vs DEDUP

Dua skenario dijalankan dengan pipeline yang sama persis (Tokenizer → HashingTF 100.000 → IDF → NaiveBayes multinomial, parameter default, split 80/20 seed 42). Selisih akurasi yang kecil membuktikan angka resmi tidak tergelembung oleh near-duplikat.
